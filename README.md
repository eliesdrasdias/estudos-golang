# Estudos de Golang

Este repositório contém meus exercícios, anotações e códigos desenvolvidos durante o aprendizado da linguagem Go. O objetivo é registrar a evolução nos fundamentos e na aplicação prática da linguagem.

## 🛠️ Tecnologias e Ferramentas
- **Go** (Golang)
- **Git** para versionamento

## 📂 Organização
O repositório está organizado por módulos de aprendizado, cobrindo:
- Sintaxe e comandos básicos
- Variáveis e tipos de dados
- Estruturas de controle
- Gerenciamento de módulos (`go.mod`)

A estrutura de pastas é atualizada conforme o progresso das aulas e novos conceitos explorados.
